# 🎾 endoIsFree

体育施設のテニスコート抽選に関する手続きをお手伝いするプログラムです 🏟️

> **🏷️ バージョン:** v2.1（開発中）

## 1. 🧭 このプログラムについて

用途に応じて、次のどちらかを実行します。

- **free（抽選申込み）：** 毎月1日から10日までの申込み期間に、設定した内容で抽選申込みを進めます。最後の確定操作はブラウザー上で利用者が行います。
- **check（抽選結果確認）：** 毎月14日から20日までの結果確認期間に、当選・落選結果を確認します。当選がある場合は確認操作を行い、完了結果を記録します。

Windows 10/11とmacOSで実行できます。ブラウザーを表示して操作するため、処理中はパソコンを起動したままにしてください。

## 2. 🛠️ 初期設定（最初の一度だけ）

Pythonと必要なプログラムをインストールします。通常は一度設定すれば、毎回の実行前に再インストールする必要はありません。

### 2-1. 📦 プロジェクトを用意する

通常はGitHubの[プロジェクトページ](https://github.com/Yang-Min-Seok/endoIsFree)から **Code → Download ZIP** を選び、ZIPを展開して使います。ZIPファイルの中から直接実行しないでください。`nightlyUpdate` を使う場合はZIPではなく、[「nightlyUpdateの設定」](#5-nightlyupdate自動更新の設定)にあるGitの取得手順を使ってください。

### 2-2. 🐍 Pythonをインストールする

- **Windows：** [Python公式サイト](https://www.python.org/downloads/)からPython 3.10以降をインストールします。インストーラーで「Add python.exe to PATH」とPython Launcherを有効にしてください。コマンドプロンプトで次を実行し、バージョンを確認します。

  ```bat
  py -3 --version
  ```

- **macOS：** Python 3.10以降がインストールされていることを確認します。

  ```bash
  python3 --version
  ```

### 2-3. ⚙️ 必要なプログラムをインストールする

プロジェクトフォルダーをコマンド画面で開き、次のコマンドを実行します。

**Windows（コマンドプロンプト）：**

```bat
py -3 -m pip install -r requirements.txt
py -3 -m playwright install chromium
```

**macOS（ターミナル）：**

```bash
python3 -m pip install -r requirements.txt
python3 -m playwright install chromium
```

この設定は初回のみ必要です。`requirements.txt` が更新された場合は、必要なプログラムを再インストールしてください。

> **🔐 パスワードについて**
>
> 設定ファイルにはパスワードが含まれます。ファイルはプロジェクト内の `endoCustom/` に保管し、他人に共有しないでください。カスタマイザーの入力内容はネットワークへ送信されません。

## 3. 🎟️ free（抽選申込み）の手順

抽選申込み期間は毎月1日から10日です。

1. `endoCustom/freeCustomizer.html` をブラウザーで開きます。
2. 利用者情報、公園・施設、利用日、活動時間を入力して設定ファイルを作成します。複数の利用者は1行ずつ入力します。
   - 2時間利用の場合は開始時刻を1つ選びます。
   - 4時間利用の場合は異なる開始時刻を2つ選びます。連続した時間帯でなくても構いません。
3. ダウンロードされた `freeConfig.json` を `endoCustom/` フォルダーに置きます。設定内容を変更しない限り、毎回作り直す必要はありません。
4. プロジェクトフォルダーからプログラムを起動します。
   - **Windows：** `freeEndo.bat` をダブルクリックします。
   - **macOS：** ターミナルで `./freeEndo.sh` を実行します。
5. 起動前に確認ダイアログが表示されます。キャンセルまたは誤答の場合、処理は始まりません。
6. ブラウザーと起動したコマンド画面を閉じずに待ちます。各利用者について2回分の申込み処理を行います。
7. 最終確認ページが表示されたら、内容を確認してブラウザー上で最終確定を行います。プログラムは最終確定を自動では行いません。

処理結果とログは `logs/freeEndo.log` で確認できます。最終確認ページで音による通知を使う場合は、`sounds/step8.wav` を配置し、パソコンの音量と出力先を確認してください。

## 4. 🔎 check（抽選結果確認）の手順

抽選結果の確認期間は毎月14日から20日です。

1. `endoCustom/checkCustomizer.html` をブラウザーで開きます。
2. 利用者番号とパスワードを入力し、設定ファイルを作成します。
3. ダウンロードされた `checkConfig.json` を `endoCustom/` フォルダーに置きます。利用者情報を変更しない限り、毎回作り直す必要はありません。
4. プロジェクトフォルダーからプログラムを起動します。
   - **Windows：** `checkEndo.bat` をダブルクリックします。
   - **macOS：** ターミナルで `./checkEndo.sh` を実行します。
5. freeと同じ確認ダイアログに回答します。キャンセルまたは誤答の場合、処理は始まりません。
6. ブラウザーと起動したコマンド画面を閉じずに待ちます。プログラムが各利用者の結果を確認し、落選・当選情報をログに記録します。
   - 当選結果は1件ずつ処理します。2件ある場合は同じ利用者で再ログインし、残りの当選結果を確認します。
   - 当選確認後、完了画面で「確認完了」と「当選の確認処理が完了しました。」の両方を検出した場合に成功とします。
   - 確認操作後に完了を確認できず「結果要確認」となった場合は、自動再試行しません。重複操作を避けるため、サイト上の状態を確認してから次の対応を判断してください。
7. 全利用者の処理結果と、当選・落選情報を `logs/checkEndo.log` で確認します。

エラーが発生した場合は、通常5秒後にstep1から最大3回（初回を含め最大4回）再試行します。確認操作後に結果が不明な場合は、再試行せず次の利用者へ進みます。

## 5. 🌙 nightlyUpdate（自動更新）の設定

自動更新は任意です。`nightlyUpdate` は**Gitで取得したプロジェクト用**です。ZIPをダウンロードして展開したフォルダーでは使えません。

自動更新を使う場合は、ZIPではなくGitでプロジェクトを取得してください。[Git](https://git-scm.com/downloads)をインストールした後、プロジェクトを置きたい場所で次を実行します。

```bash
git clone https://github.com/Yang-Min-Seok/endoIsFree.git
```

取得した `endoIsFree` フォルダーで「2-2. Pythonをインストールする」と「2-3. 必要なプログラムをインストールする」を行ってください。

> **🚨 重要：実行するとローカルの変更が失われます**
>
> スクリプトは `origin/main` に切り替えて強制的に同期し、Gitで無視されない未追跡ファイルを削除します。ローカルの変更やコミットも失われます。`ver2.1` など `main` 以外のブランチや、開発中のフォルダーでは実行しないでください。アプリケーションを終了し、必要なファイルをバックアップしてから設定してください。

### 🪟 Windows

1. スタートメニューから「タスク スケジューラ」を開き、「基本タスクの作成」を選びます。
2. タスク名を入力し、トリガーを「毎日」、時刻を希望する更新時刻（例：午前2時）に設定します。
3. 操作で「プログラムの開始」を選び、以下を設定します。`C:\endoIsFree` は実際のプロジェクトフォルダーに置き換えてください。
   - **プログラム/スクリプト：** `C:\Windows\System32\cmd.exe`
   - **引数の追加：** `/c ""C:\endoIsFree\nightlyUpdate.bat""`
   - **開始（オプション）：** `C:\endoIsFree`
4. 必要に応じて、タスクの「条件」でスリープ解除を有効にします。パソコンの電源が切れている場合やネットワークに接続されていない場合は更新されません。
5. タスクを右クリックして「実行」し、`logs\nightlyUpdate.log` で動作を確認します。

### 🍎 macOS

1. ターミナルで `EDITOR=nano crontab -e` を実行します。
2. nanoが開いたら次の行を追加し、`/path/to/endoIsFree` をGitで取得した実際のプロジェクトフォルダーに置き換えます。

   ```cron
   0 2 * * * /bin/sh "/path/to/endoIsFree/nightlyUpdate.sh"
   ```

   `Ctrl+O`、Enter、`Ctrl+X` の順に押して保存・終了します。これは毎日午前2時に更新します。Macがスリープ中または電源オフの場合は実行されないことがあります。
3. ターミナルで `/bin/sh "/path/to/endoIsFree/nightlyUpdate.sh"` を実行して動作をテストします。パスを実際のプロジェクトフォルダーに置き換えてください。結果は `logs/nightlyUpdate.log` で確認できます。

## 6. 🧰 トラブルシューティング

| 症状 | 対処方法 |
|---|---|
| `py` が認識されない（Windows） | Python Launcherを含めてPythonをインストールし直し、新しいコマンドプロンプトで確認します。 |
| `python3` が認識されない（macOS） | Python 3.10以降をインストールし、ターミナルを開き直します。 |
| `No module named playwright` | プロジェクトフォルダーで、Windowsは `py -3 -m pip install -r requirements.txt`、macOSは `python3 -m pip install -r requirements.txt` を実行します。 |
| Chromiumが見つからない | Windowsは `py -3 -m playwright install chromium`、macOSは `python3 -m playwright install chromium` を実行します。 |
| 設定ファイルが見つからない | 起動したモードに合う `endoCustom/freeConfig.json` または `endoCustom/checkConfig.json` があるか確認します。Windowsでは拡張子が `.json.json` や `.json.txt` になっていないかも確認してください。 |
| step0で開始できない | 確認ダイアログの質問に正しく回答してください。 |
| checkの結果が「結果要確認」 | サイトにログインし、当選結果が確認済みかを調べてください。重複操作防止のため、自動では再試行しません。 |
| 実行中にエラーが出る | 実行モードに対応する `logs/freeEndo.log` または `logs/checkEndo.log` を確認してください。 |

## 7. 🐛 バグレポート

不具合を見つけた場合は、[endoIsFreeのバグレポートページ](https://app.notion.com/p/Endo-is-Free-40b81c2308ff80cab8c5fa08e0659d2c)から報告をお願いします。次の3点を記載してください。

1. 発生日
2. バグの内容
3. 関連するログ（`logs/freeEndo.log` または `logs/checkEndo.log`）

設定ファイルにはパスワードが含まれるため、バグレポートに添付しないでください。
