# endoIsFree

体育施設の抽選申込みを自動化するプログラムです。

## まずはじめに

1. [初回セットアップ](#初回セットアップ)を行います。
2. [設定ファイル](#設定ファイルを作成する)を作成します。
3. お使いのOSに合わせて[プログラムを実行](#実行する)します。
4. 申込みフローでは、最終確認ページが表示された後にブラウザー上でユーザーが最終確認を行います。

## 設定ファイルを作成する

1. 申込み用は `endoCustom/freeCustomizer.html`、結果確認用は `endoCustom/checkCustomizer.html` を Microsoft Edge などのブラウザーで開きます。
2. 画面の案内に沿って必要な情報を入力します。結果確認用のページでは利用者情報のみを入力します。
3. 申込み用では `freeConfig.json`、結果確認用では `checkConfig.json` がダウンロードされます。該当するファイルをプロジェクト内の `endoCustom/` フォルダーに移動してください。
   - 以前の `endoCustom.json` を使っていた場合は、申込み用カスタマイザーで設定を作り直すか、既存ファイルを `freeConfig.json` に名前変更してください。

> **重要：パスワードの取り扱い**
>
> 設定ファイルにはパスワードが含まれます。`endoCustom/` の中に保管し、他人に共有しないでください。設定画面は入力内容をネットワークへ送信しません。

### 利用者情報と活動時間

- 利用者情報は `利用者番号,パスワード` の形式で、1行に1件入力します。
- 申込み用設定は利用者情報のほか、公園・施設・利用日・活動時間を含みます。結果確認用設定は利用者情報のみです。
- 活動時間は2時間または4時間を選べます。
  - **2時間の場合：** 開始時間を1つ選びます。
  - **4時間の場合：** 異なる開始時間を2つ選びます。時間帯は連続していなくても構いません。

## 初回セットアップ

### Windows 10 / 11

1. [GitHubのプロジェクトページ](https://github.com/Yang-Min-Seok/endoIsFree)を開き、「Code」から「Download ZIP」を選びます。ダウンロードしたZIPを右クリックして「すべて展開」を選択してください。ZIPの中から直接実行せず、展開後のフォルダーを使います。
   - `main.py`、`freeEndo.bat`、`freeEndo.ps1`、`checkEndo.bat`、`checkEndo.ps1`、`requirements.txt`、`common/`、`commonSteps/`、`freeSteps/`、`checkSteps/`、`endoCustom/` が同じプロジェクトフォルダー内にある状態にしてください。
   - 通常の実行にGitは不要です。
2. [Python公式ダウンロードページ](https://www.python.org/downloads/)からPython 3.10以降をインストールします。インストーラーでは「Add python.exe to PATH」とPython Launcherを有効にしてください。
3. Pythonのインストール後、コマンドプロンプトを開いてバージョンを確認します。表示されたバージョンが3.10以降であることを確認してください。

   ```bat
   py -3 --version
   ```

   `py` が認識されない場合は、Python Launcherを含めてインストールし直し、新しいコマンドプロンプトを開いて再確認してください。
4. 申込み用は `endoCustom/freeCustomizer.html`、結果確認用は `endoCustom/checkCustomizer.html` を開いて設定を作成します。ダウンロードした `freeConfig.json` または `checkConfig.json` をプロジェクトの `endoCustom/` フォルダーへ移動してください。
5. プロジェクトフォルダーをエクスプローラーで開き、アドレスバーに `cmd` と入力して Enter キーを押します。開いたコマンドプロンプトで次を1行ずつ実行します。

   ```bat
   py -3 -m pip install -r requirements.txt
   py -3 -m playwright install chromium
   ```

### macOS / Linux

ターミナルでプロジェクトフォルダーに移動してから、次を実行します。

```bash
python3 -m pip install -r requirements.txt
python3 -m playwright install chromium
```

## 実行する

### Windows

1. エクスプローラーでプロジェクトフォルダーを開き、`freeEndo.bat` をダブルクリックします。コマンドプロンプトを開いた状態で実行した場合は、その画面で `freeEndo.bat` と入力しても構いません。
2. ブラウザーが開いた後は処理を続けるため、ブラウザーと起動したコマンド画面を閉じないでください。
3. 最終確認ページに進むと、`sounds/step8.wav` が連続再生されます。最終確認はブラウザー上でユーザーが行ってください。確認が完了してページが移動すると音は停止します。音量を有効にし、音声出力先を利用できる状態にしてください。

`freeEndo.bat` は `freeEndo.ps1` を呼び出し、`py -3 main.py free` を実行します。申込み・結果確認のどちらも、処理中はWindowsの電源管理APIでシステムのアイドルスリープを抑止し、終了時に解除します。ノートPCの蓋を閉じた場合のスリープは防げないため、実行中は蓋を開けておいてください。

申込みの実行ログ：`logs\freeEndo.log`

抽選結果の確認には `checkEndo.bat` を実行します。step3で結果ページへ移動しますが、結果の読み取りや当選確定操作はまだ実装されていません。
結果確認の実行ログ：`logs\checkEndo.log`

### macOS / Linux

プロジェクトフォルダーで次を実行します。

```bash
./freeEndo.sh
```

macOSでは `caffeinate` で処理中のシステムアイドルスリープを一時的に抑止します。申込みと結果確認のログはそれぞれ `logs/freeEndo.log` と `logs/checkEndo.log` に記録されます。

結果確認フローは次のコマンドで起動します。

```bash
./checkEndo.sh
```

`python3 main.py free` と `python3 main.py check` で直接起動することもできます。

## プログラムの動作

### 抽選結果の確認（開発中）

- 抽選申込み期間は毎月1日から10日、結果確認期間は毎月14日から20日です。
- `checkEndo` は利用者ごとにブラウザーセッションを作成し、共通step1・2の後にcheck step3～8を実行します。
- **step3：** 抽選メニューを開き、「抽選結果」リンクを選択します。
- **step4：** `該当する抽選はありません。` があれば当選結果なし、`確認されていない当選結果` のcaptionがあれば当選結果ありと判定します。両方またはいずれも見つからない場合は画面を判定できないとして再試行します。当選結果は最大2件の可能性がありますが、件数の特定や確定操作はまだ行いません。
- **step5：** step4で当選結果なしと判定した場合、落選した申込み一覧から状態・予約番号・公園/施設・利用日・利用時間・利用料金を取得し、全利用者分を最後に一覧表示して次の利用者へ進みます。当選結果ありの場合は `step5_winner.py` に分岐しますが、現在は呼び出しログだけの仮実装です。
- **現在の実装：** 当選結果の詳細読み取りや確定操作はまだ行わないため、実際の結果確認は完了しません。
- エラーが発生した利用者は5秒待ってstep1から最大3回再試行します（初回を含め最大4回）。それでも失敗した場合は「未確認（再試行上限）」として記録し、次の利用者に進みます。
- checkの各step開始前に10秒待機し、step3ではメニューと結果リンクのクリック前にもそれぞれ5秒待機します。
- ビジネス処理が最後まで完了した利用者は、最終一覧にstep4の判定（当選結果あり／なし）を表示します。最終一覧とログは `logs/checkEndo.log` で確認できます。

### 申込みの流れ

- 設定ファイルの利用者を1件ずつ処理します。
- 各利用者について、1次・2次の申込みを続けて実行します。それぞれstep1からstep8までを実行します。
- アカウント・申込み回ごとにブラウザーセッションを分けます。
- 利用者情報はログインに使用します。
- **step4：** 抽選分類「テニス（人工芝）」を選択します。
- **step5：** 設定した公園を選択して10秒待ってから、施設を選択します。
- **step6：** 設定した月日を週ごとに検索して開始時間を選び、申込み内容の確認画面へ進みます。日付が見つからず翌週へ進めなくなった場合は処理を中断します。
- **step7：** 確認画面の内容をログに記録し、申込み回数を選択して最終確認ページへ進みます。
- **4時間活動の場合：** 各申込み回で設定した開始時間を使います。

### 待機時間

申込みフローでは、サーバー負荷を抑えるためstep8以外の各stepの開始前に10秒待機します。さらに、以下のタイミングでも追加で待機します。

step2の入力後待機は共通処理のため、結果確認フローでも行います。その他の追加待機は申込みフロー用です。

| step | 待機するタイミング | 時間 |
|---|---|---:|
| step2 | 利用者番号入力後、パスワード入力後 | 各5秒 |
| step3 | 抽選ナビゲーション、抽選申込みリンクのクリック前 | 各5秒 |
| step5 | 公園を選択してから施設を選択するまで | 10秒 |
| step6 | 日時枠を選択してから申込みボタンを押すまで | 5秒 |
| step7 | 申込み回数を選択した後 | 5秒 |

待機内容はログに記録されます。

### 最終確認

> **重要：申込みフローについて** step8では自動操作を行いません。ブラウザー画面を表示した状態で実行し、ユーザー自身が最終確認を行ってください。

- step7では申込み内容を確認し、サイトの確認ダイアログを経て最終確認ページに進みます。
- step8では最終確認ページを表示したまま音で通知し、ユーザーが最終確認を行ってページが遷移するまで待機します。待機時間に上限はありません。
- WindowsとmacOSでは `sounds/step8.wav` を非同期で連続再生し、step8を抜けると再生を停止します。WAVファイルをプロジェクト内の `sounds/step8.wav` に置いてください。
- Linuxでは端末のベルで通知し、60秒ごとに繰り返します。

### 申込みフローのエラーと再試行

- stepでエラーが発生した場合、該当する利用者・申込み回を記録し、5秒待ってstep1から最大3回まで再試行します。
- 再試行を使い切った申込みは「失敗」として記録します。プログラムは終了せず、次の申込み回へ進みます。
- step8後に完了メッセージが表示されない場合は失敗として、step1から最大3回まで再試行します。
- step7から直接、またはstep8での最終確認後にページが遷移し、「抽選の申込みが完了しました。」という完了メッセージが表示された場合に申込みを成功と判定します。
- それ以外のstep7確認後のエラーは「結果不明」として再試行しません。同じ利用者の残りの申込みもスキップし、次の利用者へ進みます。

### ログと最終結果

- 申込みフローでstepエラーが発生した場合、利用者番号、申込み回、step名、step内の処理、エラー理由をコンソールと `logs/freeEndo.log` にその場で記録します。
- 申込みフローの処理が終わると、設定内容と各利用者の1次・2次申込み結果を表形式で表示します。
- 結果は「成功」「失敗」「結果不明」「スキップ」「未実行」「中断」で表示されます。
- エラーの重複したfailure summaryは出力しません。
- 結果確認フローのエラーと最終一覧は `logs/checkEndo.log` に記録されます。結果確認の実装が完了するまでは、状態は「未確認」と表示されます。

## Windowsの自動更新（任意）

`nightlyUpdate.bat` はGitでクローンしたプロジェクトを更新するための任意のスクリプトです。ZIPをダウンロードして展開した場合は使用しないでください。

> **注意：ローカルの変更が失われる可能性があります**
>
> 実行すると `origin/main` を取得し、ローカルの `main` をリモートと同じ状態に強制リセットします。追跡対象ファイルのローカル変更・削除やローカルコミット、およびGitで無視されない未追跡ファイルは失われます。設定ファイルやログなど `.gitignore` 対象の未追跡ファイルは保持されます。必要なファイルをバックアップしてから実行してください。

### 毎日午前2時に自動更新する設定

1. Windowsのスタートメニューで「タスク スケジューラ」を検索して起動し、「基本タスクの作成」を選びます。
2. タスク名を入力し、トリガーに「毎日」、開始時刻に午前2:00を指定します。
3. 操作で「プログラムの開始」を選び、次のように設定します。`C:\endoIsFree` は実際にプロジェクトを展開したフォルダーに置き換えてください。
   - **プログラム/スクリプト：** `C:\Windows\System32\cmd.exe`
   - **引数の追加：** `/c ""C:\endoIsFree\nightlyUpdate.bat""`
   - **開始（オプション）：** `C:\endoIsFree`
4. 作成後、タスクのプロパティを開き、「条件」タブで必要に応じて「タスクを実行するためにスリープを解除する」を有効にします。
   - PCの電源が切れている場合やネットワークに接続されていない場合は更新されません。
   - 予定時刻に実行できなかった場合にも後から実行したい場合は、「設定」タブで「スケジュールされた時刻にタスクを開始できなかった場合、すぐにタスクを実行する」を有効にします。
5. ネットワークに接続できる状態であることを確認し、タスクを右クリックして「実行」を選ぶと動作をテストできます。実行結果は `logs\nightlyUpdate.log` で確認してください。

更新処理は `main` を `origin/main` に強制的に合わせるため、午前2時にアプリケーションを実行中にしないでください。GitHub認証が必要なリポジトリでは、タスク実行ユーザーからも認証できるように設定してください。

## トラブルシューティング

| 症状 | 対処方法 |
|---|---|
| `py` が認識されない | Python Launcherを含めてPythonをインストールし直し、新しいコマンドプロンプトを開いてください。 |
| `No module named playwright` と表示される | プロジェクトフォルダーで `py -3 -m pip install -r requirements.txt` を実行してください。 |
| Chromiumが見つからないというエラーが出る | `py -3 -m playwright install chromium` を実行してください。 |
| 設定ファイルが見つからないというエラーが出る | 起動したフローに応じて `endoCustom/freeConfig.json` または `endoCustom/checkConfig.json` があるか確認してください。Windowsで拡張子が非表示の場合、誤って `.json.json` や `.json.txt` になっていないかも確認してください。 |
| 音が聞こえない | Windowsの音量、ミュート状態、選択中の音声出力先を確認してください。 |
| `A visible browser is required` と表示される | 設定ファイルを作り直し、ブラウザー画面を表示する設定で保存してください。 |
| 上記以外のエラー | 実行したフローに対応する `logs/freeEndo.log` または `logs/checkEndo.log` を確認してください。インストールや起動にはインターネット接続が必要です。 |
