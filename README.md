# endoIsFree

## バージョン

v1.0.0（開発中）

## 使い方

### 設定ファイルの作成

1. プロジェクトフォルダー内の `endoCustom/customizer.html` を Microsoft Edge などのブラウザーで開きます。設定画面は入力内容をネットワークへ送信しません。
2. 画面の案内に沿って利用者情報、公園・施設、利用日、開始時間を入力します。
3. ダウンロードした `endoCustom.json` を、プロジェクト内の `endoCustom/` フォルダーに移動します。`customizer.html` と同じフォルダーに置いてください。既存の設定ファイルがある場合は、必要に応じて置き換えます。

利用者情報は `利用者番号,パスワード` の形式で1行に1件入力します。設定ファイルにはパスワードが含まれます。`endoCustom/` の中に保管し、他人に共有しないでください。このHTMLは入力内容をネットワークへ送信しません。

活動時間は2時間または4時間を選べます。2時間の場合は開始時間を1つ、4時間の場合は開始時間を異なる時間で2つ選びます。4時間の場合、選ぶ時間帯は連続していなくても構いません。

step8でユーザーが最終確認を行うため、ブラウザー画面を表示して実行する必要があります。

利用者情報はログインに使用します。step4では抽選分類「テニス（人工芝）」を選択し、step5では設定した公園を選択して10秒待ってから施設を選択します。step6では設定した月日を週ごとに検索して開始時間を選び、申込み内容の確認画面へ進みます。日付が見つからず翌週へ進めなくなった場合は処理を中断します。step7では確認画面の内容をログに記録して申込み回数を選択し、最終確認ページへ進みます。step8ではユーザーが最終確認を行います。利用者ごとに1次・2次の申込みを続けて実行し、4時間活動では各回に設定した開始時間を使います。

アプリケーションは設定ファイルの利用者を1件ずつ処理し、各利用者についてstep1からstep8までを2回実行します。アカウント・申込み回ごとにブラウザーセッションを分けます。step8はユーザーによる操作が必要なため、ブラウザーを表示する設定が必須です。サーバー負荷を抑えるため、step8以外の各stepの開始前に10秒待機します。さらに、step2では利用者番号入力後とパスワード入力後、step3では抽選ナビゲーションと抽選申込みリンクのクリック前、step6では日時枠選択後の申込みボタンを押す前、step7では申込み番号選択後に、それぞれ5秒待機し、待機内容をログに記録します。stepでエラーが発生した場合は、該当する利用者・申込み回を記録し、5秒待ってstep1から最大3回まで再試行します。step7では申込み内容を確認し、サイトの確認ダイアログを経て最終確認ページに進みます。step8では最終確認ページを表示したまま音で通知し、最終確認操作をユーザーに委ねます。自動操作は行わず、ユーザーが最終確認を行ってページが遷移するまで待機します。10秒ごとに操作を促す音を繰り返し、操作完了まで待機時間に上限を設けません。step7から直接、またはstep8での最終確認後にページが遷移し、「抽選の申込みが完了しました。」という完了メッセージが表示された場合に申込みを成功と判定します。step8後に完了メッセージが表示されない場合は失敗として、step1から最大3回まで再試行します。それ以外のstep7確認後のエラーは結果不明として再試行せず、同じ利用者の残りの申込みもスキップして次の利用者へ進みます。Windowsではシステム通知音、macOSではシステム効果音、Linuxでは端末のベルを使用します。Linuxでは端末側のベル音が有効である必要があります。

各stepでエラーが発生した場合は、利用者番号、申込回、step名、step内の処理、エラー理由をその場でコンソールと `logs/endoIsFree.log` に記録します。全処理の最後には設定内容と、各利用者の1次・2次申込みの結果（成功、失敗、結果不明、スキップ、未実行、中断）を表形式で表示します。エラーの重複したfailure summaryは出力しません。

### 初回セットアップ

#### Windows 10 / 11

1. [GitHubのプロジェクトページ](https://github.com/Yang-Min-Seok/endoIsFree)を開き、「Code」から「Download ZIP」を選びます。ダウンロードしたZIPを右クリックして「すべて展開」を選択してください。ZIPの中から直接実行せず、展開後のフォルダーを使います。`main.py`、`freeEndo.bat`、`freeEndo.ps1`、`requirements.txt`、`steps/`、`common/`、`endoCustom/` が同じプロジェクトフォルダー内にある状態にしてください。Gitは通常の実行には不要です。
2. [Python公式ダウンロードページ](https://www.python.org/downloads/)からPython 3.10以降をインストールします。インストーラーでは「Add python.exe to PATH」とPython Launcherを有効にしてください。
3. Pythonのインストール後、コマンドプロンプトを開いて `py -3 --version` を実行し、表示されたバージョンが3.10以降であることを確認します。`py` が認識されない場合はPython Launcherを含めてインストールし直し、新しいコマンドプロンプトを開いて再確認してください。
4. エクスプローラーでプロジェクト内の `endoCustom/customizer.html` を Microsoft Edge などで開き、設定を作成します。通常は `Downloads` フォルダーに保存された `endoCustom.json` を、プロジェクトの `endoCustom/` フォルダーへ移動してください。ファイル名が正確に `endoCustom.json` であることを確認します。
5. プロジェクトフォルダーをエクスプローラーで開き、アドレスバーに `cmd` と入力して Enter キーを押します。開いたコマンドプロンプトで次を1行ずつ実行します。

   ```bat
   py -3 -m pip install -r requirements.txt
   py -3 -m playwright install chromium
   ```

#### macOS / Linux

ターミナルでプロジェクトフォルダーに移動してから、次を実行します。

- macOS / Linux:
  1. `python3 -m pip install -r requirements.txt`
  2. `python3 -m playwright install chromium`

### 実行（Windows）

1. エクスプローラーでプロジェクトフォルダーを開き、`freeEndo.bat` をダブルクリックします。コマンドプロンプトを開いた状態で実行した場合は、その画面で `freeEndo.bat` と入力しても構いません。
2. ブラウザーが開いた後は処理を続けるため、ブラウザーと起動したコマンド画面を閉じないでください。
3. 最終確認ページに進むと、10秒ごとにシステム音で通知します。ブラウザー上の最終確認はユーザーが行ってください。確認が完了してページが移動するまで、処理は待機します。音量を有効にし、音声出力先を利用できる状態にしてください。

Windowsでは `freeEndo.bat` が `freeEndo.ps1` を呼び出し、`py -3` で `main.py` を実行します。処理中はWindowsの電源管理APIでシステムのアイドルスリープを抑止し、終了時に解除します。ノートPCの蓋を閉じた場合のスリープは防げないため、実行中は蓋を開けておいてください。
実行ログは `logs\endoIsFree.log` に記録されます。
`nightlyUpdate.bat` はGitでクローンしたプロジェクトを更新するための任意のスクリプトです。ZIPをダウンロードして展開した場合は使用しないでください。

### 実行（macOS / Linux）

- `./freeEndo.sh`

macOSでは `caffeinate` で処理中のシステムアイドルスリープを一時的に抑止します。ログは `logs/endoIsFree.log` に記録されます。

### Windowsで問題が起きたとき

- `py` が認識されない: Python Launcherを含めてPythonをインストールし直し、新しいコマンドプロンプトを開いてください。
- `No module named playwright` と表示される: プロジェクトフォルダーで `py -3 -m pip install -r requirements.txt` を実行してください。
- Chromiumが見つからないというエラーが出る: `py -3 -m playwright install chromium` を実行してください。
- 設定ファイルが見つからないというエラーが出る: `endoCustom/endoCustom.json` というパスとファイル名を確認してください。Windowsで拡張子が非表示の場合、誤って `.json.json` や `.json.txt` になっていないかも確認してください。
- 音が聞こえない: Windowsの音量、ミュート状態、選択中の音声出力先を確認してください。
- `A visible browser is required` と表示される: 設定ファイルを作り直し、ブラウザー画面を表示する設定で保存してください。
- 詳細なエラーは `logs/endoIsFree.log` を確認してください。インストールや起動にインターネット接続が必要です。
