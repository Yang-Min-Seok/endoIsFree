# endoIsFree

## バージョン

v1.0.0（開発中）

## 使い方

### 設定ファイルの作成

1. `endoCustom/customizer.html` をブラウザーで開きます。
2. 画面の案内に沿って利用者情報、公園・施設、利用日、開始時間を入力します。
3. ダウンロードした `endoCustom.json` をプロジェクト内の `endoCustom/` フォルダーに移動します。

利用者情報は `利用者番号,パスワード` の形式で1行に1件入力します。設定ファイルにはパスワードが含まれます。`endoCustom/` の中に保管し、他人に共有しないでください。このHTMLは入力内容をネットワークへ送信しません。

活動時間は2時間または4時間を選べます。2時間の場合は開始時間を1つ、4時間の場合は開始時間を異なる時間で2つ選びます。4時間の場合、選ぶ時間帯は連続していなくても構いません。

作成画面ではブラウザー画面を表示するか、バックグラウンドで実行するかを選べます。初期値は画面表示です。

利用者情報はログインに使用します。step4では抽選分類「テニス（人工芝）」を選択し、step5では設定した公園を選択して10秒待ってから施設を選択します。step6では設定した月日を週ごとに検索して開始時間を選び、申込み内容の確認画面へ進みます。日付が見つからず翌週へ進めなくなった場合は処理を中断します。step7では確認画面の内容をログに記録し、申込み回数を選んで申込みを送信します。利用者ごとに1次・2次の申込みを続けて実行し、4時間活動では各回に設定した開始時間を使います。

アプリケーションは設定ファイルの利用者を1件ずつ処理し、各利用者についてstep1からstep7までを2回実行します。アカウント・申込み回ごとにブラウザーセッションを分けます。サーバー負荷を抑えるため、各stepの開始前に10秒待機します。さらに、step2では利用者番号入力後とパスワード入力後、step3では抽選ナビゲーションと抽選申込みリンクのクリック前、step6では日時枠選択後の申込みボタンを押す前、step7では申込み番号選択後に、それぞれ5秒待機し、待機内容をログに記録します。stepでエラーが発生した場合は、該当する利用者・申込み回を記録し、5秒待ってstep1から最大3回まで再試行します。最終申込み時に通信エラーのダイアログが表示された場合は、そのエラーを閉じ、後続の確認ダイアログでは申込みを確定せずに再試行します。最終確認ダイアログで申込みを確定した後は、次のページへの遷移を待ち、結果を目視確認できるよう確定時点から最低20秒間ブラウザーを開いたままにします。その後にエラーが発生した場合は、その申込み回を再試行せず、同じ利用者の残りの申込みもスキップして次の利用者へ進みます。処理終了時、再試行を行ったケースや結果不明でスキップしたケースがあれば、利用者・申込み回・結果をログ末尾にまとめて表示します。

### 初回セットアップ

- Python 3.10以降をインストールしてください。まだ入っていない場合は [Python公式ダウンロードページ](https://www.python.org/downloads/) からインストーラーを取得します。
- Windowsではインストール時に「Add python.exe to PATH」とPython Launcherを有効にしてください。インストール後、コマンドプロンプトで `py -3 --version` を実行して確認します。
- macOS / Linuxではターミナルで `python3 --version` を実行して確認します。

- macOS / Linux:
  1. `python3 -m pip install -r requirements.txt`
  2. `python3 -m playwright install chromium`
- Windows:
  1. `py -3 -m pip install -r requirements.txt`
  2. `py -3 -m playwright install chromium`

### 実行

- macOS / Linux: `./freeEndo.sh`
- Windows: `freeEndo.bat`

どちらもスクリプト自身のあるディレクトリから `main.py` を実行します。macOSでは `caffeinate`、WindowsではWindowsの電源管理APIを使い、処理中のシステムアイドルスリープを一時的に抑止します。Windowsでは `freeEndo.ps1` を使用します。ノートPCの蓋を閉じた場合のスリープは防げないため、実行中は蓋を開けておいてください。処理の終了後、スリープ抑止は解除されます。実行ログは `logs/endoIsFree.log` に記録されます。更新スクリプトの実行結果は `logs/nightlyUpdate.log` に追記されます。
