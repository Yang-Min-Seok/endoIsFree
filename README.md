# 🎾 endoIsFree

> **エンドーは自由なのか？**
> まずはコートの抽選に申し込んでから考えよう。

東京都公園協会のテニスコート抽選申し込みを、少しでも楽にするための小さな個人プロジェクトです。
エンドーのお願いで始まりましたが、当選までは保証できません。そこはコートと運にお任せです。

## 現在の状況

**要件定義中** — 自動申し込み機能は、まだ実装していません。

どのアカウントで、どのコートや日程に申し込むかを整理してから作る予定です。
目指すのは、約30人分の抽選申し込みを自動化するところまで。当選するかどうかは運にお任せ。

## 目指すこと

- 複数アカウントでの抽選申し込みを、まとめて管理する
- 申し込み内容や結果を分かりやすく確認できるようにする

## 対象サイト

[都立公園スポーツ施設予約システム](https://kouen.sports.metro.tokyo.lg.jp/web/)

## お約束

- サイトの利用規約と運営方針を確認し、遵守します。
- アカウントの所有者の許可なく、そのアカウントを利用しません。
- 自動化が禁止・制限されている場合や、制限の回避が必要な場合は実行しません。
- パスワードや認証情報をリポジトリに登録しません。エンドーの秘密はエンドーのもの。
- 抽選結果は保証できません。抽選ですから。🎲

まだ実装前のため、今のところ使い方はありません。
要件が決まったら、セットアップ方法とあわせてここに追記します。
